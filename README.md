# Battle Arena — 2D Survival

Game arcade survival sederhana berbasis HTML, CSS, dan JavaScript murni.

## Cara menjalankan
1. Download atau clone repository ini.
2. Buka `index.html` di browser.

## Kontrol
- `W A S D` atau tombol panah: bergerak.
- `Space`: jeda / lanjut.
- Di HP: gunakan tombol arah di bawah arena.
- Pemain menembak otomatis ke robot terdekat.

## Deploy ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload `index.html`, `style.css`, `script.js`, dan `README.md` ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu proses selesai. GitHub akan menampilkan URL game kamu.

Tidak membutuhkan instalasi atau library tambahan.
